# NetWatch

Moniteur de réseau en Bash : détecte les machines apparues ou disparues
entre deux scans nmap, génère un rapport et tient un journal.

## Utilisation

  bash
cp config.example.conf config.conf   # puis adapter le réseau
./netwatch.sh


## Prérequis

nmap

## Avertissement

À utiliser uniquement sur ses propres réseaux ou avec une autorisation écrite.
